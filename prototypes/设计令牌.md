# 党建管理系统 · 定制化设计令牌文档（Design Tokens）

> 版本：V1.0 · 供下游「交互式 HTML 原型构建」直接消费
> 依据：`党建管理系统页面结构交互说明与视觉规范.md`（强制约束，100% 遵循）+ 需求摘要第二节
> 设计系统选型：**IBM Carbon（企业级/政务后台标杆）** 为主选参考，补充 Stripe 数据可视化语言与 Tech Utility 大屏深色方向。
> 说明：色彩、字号、栅格、状态语义均为《视觉规范》锁死值，本令牌仅在其之上补充**组件语言、间距节奏、阴影/圆角细节、图表风格、大屏深色语言**等非锁死环节。

### 1.2 状态语义色（强制语义，锁死"色→义"映射）

红=风险/须处理 · 橙=即将到期/待补充 · 蓝=处理中/提示 · 绿=已完成 · 灰=非活跃/不可用。
状态标签**必须含文字 + 色块**，不依赖颜色单独传达。下表中 `--state-*-bg` 为浅色底、`--state-*-text` 为加深色文字（满足 WCAG AA 在浅底上的对比度）、`--state-*-dot` 为实心指示点。

| Token | HEX | 用途 | 对比度（文字/浅底） |
|-------|-----|------|------|
| `--state-red` | `#C21F30` | 风险/逾期/驳回/异常/终止 | — |
| `--state-red-bg` | `#FCE9EB` | 红标签底 | — |
| `--state-red-text` | `#A3162A` | 红标签文字（加深保 AA） | ≥ 5.0:1 |
| `--state-orange` | `#D97706` | 即将逾期/待审核 | — |
| `--state-orange-bg` | `#FCEFD9` | 橙标签底 | — |
| `--state-orange-text` | `#9A5B04` | 橙标签文字（加深保 AA） | ≥ 4.8:1 |
| `--state-blue` | `#2D6DB5` | 处理中/待办/公示中/在途 | — |
| `--state-blue-bg` | `#E7F0FA` | 蓝标签底 | — |
| `--state-blue-text` | `#1E4E8C` | 蓝标签文字（加深保 AA） | ≥ 5.2:1 |
| `--state-green` | `#2E8B57` | 已完成/已接收/已归档 | — |
| `--state-green-bg` | `#E6F4EC` | 绿标签底 | — |

| `--state-gray-bg` | `#EEF0F2` | 灰标签底 | — |
| `--state-gray-text` | `#4B5563` | 灰标签文字 | ≥ 4.6:1 |

> 流程/转接补充语义：公示中·转接在途·待回执 → 蓝；异议中·转接异常·已终止 → 红；已归档·已接收 → 绿。

## 2. 字体令牌（Typography Tokens）

### 2.1 字体栈（信创兼容 · 无 Web 字体依赖）

```css
--font-sans: "Microsoft YaHei", "微软雅黑", "PingFang SC", "Source Han Sans SC",
             "思源黑体", "Noto Sans CJK SC", "WenQuanYi Micro Hei", "文泉驿微米黑",
             -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue",
             Arial, sans-serif;
--font-num: var(--font-sans); /* 数字统一用同栈 + tabular-nums */
```

> 信创适配：优先微软雅黑/思源黑体，依次回退 统信UOS·麒麟 自带 Noto/文泉驿；不使用外链字体，满足"资源内联、无外部依赖"。

### 2.2 字号阶梯（强制锁死 20/16/14/12）

| Token | 尺寸 | 字重 | 行高 | 用途 |
|-------|------|------|------|------|
| `--fs-title` | 20px | 700 | 1.4 (28px) | 页面标题 |
| `--fs-module` | 16px | 600 | 1.5 (24px) | 模块标题 |
| `--fs-body` | 14px | 400 | 1.6 (22px) | 正文/表格 |
| `--fs-caption` | 12px | 500 | 1.5 (18px) | 辅助信息/标签 |
| `--fs-flip` | 44px | 700 | 1.1 | 大屏翻牌数字（仅驾驶舱） |

> 字重约定：400 正文 · 500 标签/说明 · 600 模块标题 · 700 页面标题与数字。

### 3.2 间距阶梯（基准 12 / 16 网格）

| Token | 值 | 用途 |

| `--space-8` | 32px | 区块间距 |
| `--space-10` | 40px | 大间距 |
| `--space-12` | 48px | 主要分隔 |

### 3.3 圆角 / 边框 / 阴影

```css
--radius-sm: 4px;   /* 标签、小型控件 */
--radius-md: 6px;   /* 按钮、输入框、卡片默认 */
--radius-lg: 8px;   /* 弹窗、大卡片 */
--radius-pill: 999px; /* 徽标、头像 */

--border-color: #E5E7EB;   /* 1px 浅灰描边 */
--border-light: #EEF0F2;   /* 更浅分隔 */
```

| 层级 | Token | 阴影值 | 用途 |
|------|-------|--------|------|
| 平 | `--shadow-none` | none | 默认表面（仅边框） |
| 微 | `--shadow-xs` | `0 1px 2px rgba(31,35,41,0.06)` | 卡片悬浮/raised |
| 浅 | `--shadow-sm` | `0 2px 8px rgba(31,35,41,0.08)` | 抽屉、下拉、提示 |
| 中 | `--shadow-md` | `0 6px 16px rgba(31,35,41,0.12)` | 弹窗、二次确认 |

> 阴影原则：PC 端默认无阴影、以 1px 边框定义边界；仅悬浮态/浮层用 xs–md 弱阴影，严禁重投影破坏庄重感。

### 3.4 层级（Z-index）

`base 0` · `dropdown 100` · `sticky(顶栏/导航) 200` · `mask 350` · `drawer 300` · `modal 400` · `toast 500`

## 4. 组件令牌（Component Tokens）

### 4.1 按钮（Button）

| 变体 | 背景 | 文字 | 边框 | 尺寸（高/内边距） | 悬浮/禁用 |
|------|------|------|------|------|------|
| 主按钮 Primary | `--brand-red` | #FFFFFF | 无 | 32px（大36）/ 0 16px | hover `#A3162A`；disabled 浅红底 `#F0C9CD` |
| 次按钮 Secondary | `#FFFFFF` | `--text-primary` | 1px `--border-color` | 同主 | hover 底 `#F5F6F8`；disabled 底 `#F5F6F8` 文字灰 |
| 文字按钮 Ghost | 透明 | `--brand-red` | 无 | 同主 | hover 底 `rgba(194,31,48,0.06)` |
| 危险按钮 Danger | `--brand-red` | #FFFFFF | 无 | 同主 | 同主；语义靠图标 + 二次确认弹窗区分 |

> 说明：主按钮与危险按钮同色（党建红）——本系统不引入第二主色，避免破坏庄重；危险语义由"警告图标 + 二次确认弹窗 + 必填原因"承载。

### 4.2 状态标签（Status Tag）— 文字 + 色块强制

通用规格：高 22px，内边距 0 8px，圆角 `--radius-sm`，左侧 6px 实心点（`--state-*-dot`），文字用 `--state-*-text`，背景 `--state-*-bg`。

| 状态 | 背景 | 文字 | 点 | 示例文案 |
|------|------|------|----|---------|
| 红 risk | `--state-red-bg` | `--state-red-text` | `--state-red` | 逾期 / 驳回 / 异议中 / 转接异常 |
| 橙 soon | `--state-orange-bg` | `--state-orange-text` | `--state-orange` | 待完善 / 待审核 / 即将逾期 |
| 蓝 proc | `--state-blue-bg` | `--state-blue-text` | `--state-blue` | 进行中 / 待办 / 公示中 / 在途 |
| 绿 done | `--state-green-bg` | `--state-green-text` | `--state-green` | 已归档 / 已通过 / 已接收 |
| 灰 idle | `--state-gray-bg` | `--state-gray-text` | `--state-gray` | 草稿 / 已撤销 / 无权限 |

### 4.3 卡片（Card）

背景 `--bg-card`；边框 1px `--border-color`；圆角 `--radius-md`（大卡 `--radius-lg`）；内边距 `--space-6`(24px)；默认无阴影、hover `--shadow-xs`；标题 16px/600，正文 14px。

### 4.4 表格（Table）

表头底 `#FAFBFC`、文字 `--text-secondary` 12–14px 中粗；行高 44px（紧凑）/ 48px；行底分隔 1px `--border-light`；行悬浮底 `#F5F6F8`；单元格内边距 12px 16px；表头固定；状态列内嵌状态标签；行内快捷操作（文字按钮）。

### 4.5 表单控件（Input / Select）

高 32px（大 36px）；边框 1px `--border-color`；圆角 `--radius-md`；内边距 0 12px；placeholder `--state-gray`(#9CA3AF)；聚焦：边框 `--brand-blue` + 外环 `0 0 0 3px rgba(45,109,181,0.12)`；禁用底 `#F5F6F8` 文字 `#B0B5BD`。

### 4.6 步骤条（Steps）— 发展党员 25 节点

节点圆 24px，连接线 2px；当前节点高亮。状态色映射：未开始=灰、进行中=蓝(实心)、待校验=蓝(描边)、已通过=绿、已驳回=红、终止=红(✕)、退回=橙。每节点标注主办角色与法定前置条件（右侧固定流程时间轴同步呈现）。

### 4.7 选项卡（Tabs）

下划线式：激活态文字 `--text-primary` + 底部 2px `--brand-red` 指示条；未激活文字 `--text-secondary`；高度 40px，字号 14px；hover 文字加深。

### 4.8 抽屉（Drawer · 右侧全局）

宽 `--aside-width`(360/420px)；背景 `#FFFFFF`；左侧 1px 描边 + `--shadow-sm`；遮罩 `rgba(0,0,0,0.45)`；头部 56px（标题 16px + 关闭）；主体内边距 `--space-6`；右侧滑入。用于消息/待办/操作详情不离页查看。

### 4.9 弹窗（Modal · 含二次确认）

宽 420px（二次确认可窄至 400px）；圆角 `--radius-lg`；阴影 `--shadow-md`；遮罩 `rgba(0,0,0,0.45)`。二次确认（危险/高风险）须：警告图标 + 红色强调 + 明确后果文案 + 必填原因输入 + [取消][确认] 右对齐。高风险操作（撤销/合并/划转/导出/核心字段变更）强制触发。

### 4.10 徽标（Badge）

实心计数：最小宽 16px、高 16px、圆角 `--radius-pill`、字号 11px、底 `--brand-red` 文字 #FFFFFF（通知/待办数）。中性计数用 `--state-gray` 底。

## 5. 大屏专用令牌（Big Screen Tokens · 党委数据驾驶舱）

- **背景**：`linear-gradient(180deg, var(--screen-bg-top) 0%, var(--screen-bg-bottom) 100%)`；面板 `--screen-panel`，卡片 `--screen-card`，描边 `--screen-border`。
- **图表强调色**：采用 §1.4 序列 `--chart-1`…`--chart-8`，在深色上保持高饱和可辨；状态语义与 PC 端一致（红/橙/蓝/绿）。
- **翻牌数字（Flip Number）**：字号 `--fs-flip`(44px)、字重 700、`font-variant-numeric: tabular-nums`、字距 1px、颜色 `--screen-text`；高亮值用 `--chart-8`(#F2D873) 或 `--chart-3`(#5B9BD9)；克制的辉光 `text-shadow: 0 0 12px rgba(91,155,217,0.25)`。
- **区块圆角 / 描边 / 辉光克制原则**：
  - 圆角 6–8px（与 PC 端一致）；
  - 描边 1px `--screen-border`，替代阴影；
  - 辉光克制：仅核心指标/预警可加极弱外发光（如 `0 0 0 1px rgba(91,155,217,0.15)` 或顶部 2px 强调线），**禁止**大范围霓虹辉光、渐变光斑、动态流光；
  - 底部红色滚动预警栏：底 `#2A1418`、文字 `--state-red`(亮化 `#E25A6B`)、滚动条目可点击下钻。

## 7. 注意事项（Cautions · 一致性约束）

### Never Do
- 大面积使用党建红作背景或装饰（仅用于品牌/主按钮/关键预警）。
- 引入第二主色或花哨渐变、重投影、霓虹辉光（破坏政务庄重）。
- 状态标签仅靠颜色传达——必须文字 + 色块。
- 使用外链 Web 字体或外部依赖（违背信创兼容与"可双击运行"要求）。
- 变更 §1/§2/§3 锁死的色值、字号、栅格尺寸。

### Prefer
- PC 端以 1px 边框定义边界，阴影仅用于悬浮/浮层（xs–md）。
- 大屏以描边 + 极弱辉光替代阴影；状态色与 PC 端语义一致。
- 高风险操作统一走二次确认弹窗 + 必填原因 + 审计留痕。
- 所有新增组件（状态机/公示/导入/证明/举报/申诉）沿用上述令牌，保持视觉与交互一致。
