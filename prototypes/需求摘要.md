# 党建管理系统 · 原型设计《需求摘要》

> 版本：V1.0 · 依据《视觉规范》+ 补充修订 PRD（蓝色标注项）
> 产出目的：作为下游「设计系统选择」与「交互式 HTML 原型构建」的统一输入
> 由需求发现分析师（许明需）产出，主理人（画统筹）归档

## 一、设计五要素

| 维度 | 结论 |
|------|------|
| 场景 Surface | PC Web 管理端（1440 基准，浏览器直览）+ 党委数据驾驶舱大屏（16:9 深色指挥端）。本期交付：4 个 PC 管理页 + 1 个大屏 |
| 受众 Audience | 核心用户为党委/党总支/支部党务工作者（G 端国企与政府单位）；驾驶舱面向党委领导与督导人员。非技术背景为主，审美预期偏向"严肃、规整、可信赖" |
| 调性 Tone | 「政务庄重型」——以 Modern Minimal 的政务变体为基底：克制留白、细边框弱阴影、信息密度高、弱化装饰。党建红仅用于品牌与关键动作，管理端避免大面积红色 |
| 品牌上下文 Brand Context | 已有完整《视觉规范》作为品牌资产，须 100% 遵循其色板/字号/栅格/状态语义；无外部品牌模仿需求。新增组件（状态机/公示/导入/证明/举报/申诉）须融入既有语言 |
| 规模 Scale | 首批 5 个核心页面；交付为交互式 HTML 原型（含基础交互、资源内联、可独立运行）；PC 端需兼容 1440 与 1366，大屏固定 16:9 |

## 二、视觉约束提取（设计系统输入）

### 2.1 色彩系统（强制）
| 用途 | 色值 | 说明 |
| 品牌党建红 | #C21F30 | Logo、主按钮、关键预警；不作长篇背景 |
| 荣誉暖金 | #C89A4B | 达标、荣誉、重点提示 |
| 信息政务蓝 | #2D6DB5 | 数据、处理中、链接与信息提示 |
| 成功绿 | #2E8B57 | 完成、归档、已缴费 |
| 警示橙 | #D97706 | 即将逾期、待完善、待审核 |
| 页面背景 | #F5F6F8 | PC 工作区背景 |
| 卡片白 | #FFFFFF | 卡片、表格、弹窗背景 |
| 正文深灰 | #1F2329 | 主要文字 |
| 辅助灰 | #6B7280 | 时间、说明、次要信息 |

大屏端：深蓝灰背景（#0F1B2D / #12233B 系），图表用高饱和强调色，状态色与 PC 端语义一致。

### 2.2 字号规范
页面标题 20px / 模块标题 16px / 正文·表格 14px / 辅助信息 12px；中文字体：微软雅黑、思源黑体或系统无衬线（信创兼容）。

### 2.3 栅格与间距（PC 端）
设计基准宽 1440px；左导航 216px；顶栏 64px；内容区外边距 24px；卡片间距 16px；列间距/内边距以 12/16 为基准网格。

### 2.4 圆角与阴影
卡片与表单控件圆角 4–8px；以细边框（1px 浅灰描边）为主，弱化阴影（仅必要层级/悬浮态轻微阴影）。

### 2.5 状态语义色（强制，标签须含文字不依赖颜色）
| 颜色 | 含义 | 典型状态 |
| 红 | 风险/必须处理 | 逾期、驳回、红色预警、异议中、转接异常/已终止 |
| 橙 | 即将到期/待补充 | 待完善、待审核、即将逾期 |
| 蓝 | 处理中/提示 | 进行中、待办理、公示中、转接在途/待回执、申诉待审核 |
| 绿 | 已完成 | 已归档、已通过、已缴费、已接收 |
| 灰 | 非活跃/不可用 | 草稿、已撤销、无权限 |

### 2.6 共性结构（所有 PC 页统一）
1. 顶部工具栏：面包屑 + 全局搜索 + 消息 + 帮助 + 当前组织 + 个人菜单
2. 左侧导航：当前模块高亮，菜单按角色/权限动态显示
3. 内容区：列表页＝筛选区→工具栏→数据表格→分页；详情页＝摘要卡→Tab 内容→流程/操作记录
4. 全局右侧抽屉：消息/待办/操作详情可不离页查看

## 三、逐页需求拆解

### 3.1 首页工作台（4.1）PC
- 目标：一个页面完成"看到要办的事、识别风险、进入高频工作"。
- 核心模块/组件：顶部问候+组织+日期+快捷操作（新建活动/发起流程/导入党员）；第一行四指标卡（待办审批/即将逾期/红色预警/本月完成率）；第二行「我的待办（按紧急度）」+「重点预警（原因/责任对象/处置入口）」；第三行「组织生活日历」+「组织生活/学习/党费三项趋势图」；底部「常用入口 + 最近浏览/导出记录」。
- 关键交互：指标卡点击下钻对应清单；待办按紧急度（红>橙>蓝）排序可直达；预警项直达处置；日历可切换月份。
- 必须体现的状态与数据：四指标卡数值+完成率+趋势；待办紧急分级；预警红色高亮。
- 蓝色新增项覆盖：顶部「导入党员」呼应账号批量导入；为「党总支/审计」角色预留菜单差异占位。

### 3.2 组织与党员（4.2）PC
- 目标：组织全生命周期 + 党员全量管理，支持四级穿透与脱敏合规。
- 核心模块/组件：左侧可搜索可展开四级组织树（无权节点仅显示名称不可进详情）；右侧组织概览+班子成员+党员概况+任期倒计时+沿革记录；党员名册（筛选：组织范围/身份/党籍状态/是否流动/积分区间）；名册表格（姓名/组织/身份/入党时间/党费状态/学习完成率/积分，身份证手机号默认脱敏）；党员档案＝摘要卡+Tab（基础信息/党籍/组织生活/学习/党费/奖惩/异动/操作记录）；发展党员入口；组织关系转接入口。
- 关键交互：组织树搜索/展开/定位；高风险操作（撤销/合并/划转）入"更多操作"并触发二次确认+填因+上传材料+选接收组织+审批；存在未结流程时按钮禁用并写明拦截原因；档案核心字段变更/查看明文/导出均二次验证并写审计；右侧抽屉查看详情不离页。
- 必须体现的状态与数据：党籍状态色标；任期倒计时；脱敏展示（查看明文需二次验证）；组织树层级与权限隔离。
- 蓝色新增项覆盖（验收要点②）：组织关系转接子页状态机——列表状态（待发起/在途/待回执/已接收/转接异常/已终止）；详情状态机视图＝发起→组织内审批→上级党委转出→对方党委接收→回执归档；「在途/待回执」蓝、「转接异常/已终止」红须处置、「已接收」绿；跨省异常须有异常原因+重新发起+人工兜底入口并通知双方管理员。

### 3.3 发展党员（4.2 子页）PC
- 目标：25 节点刚性流程线上管控、自动校验、材料归档，全程留痕。
- 核心模块/组件：25 节点阶段化步骤条（申请入党→培养考察→发展对象→接收预备→转正归档），每节点标注主办角色与法定前置条件；当前节点区仅展示本阶段表单/材料/规则；右侧固定流程时间轴（节点/办理人/意见/附件）；提交前校验清单。
- 关键交互：步骤条点击查看节点详情；当前节点表单提交；校验失败（时间不足/材料缺失/人数不达标）时提交按钮禁用并列出失败项；流程时间轴点击查看附件。
- 必须体现的状态与数据：节点状态（未开始/进行中/待校验/已通过/已驳回）；主办角色；流程时间轴完整。
- 蓝色新增项覆盖（验收要点①）：
  - 法定公示节点：在「确定入党积极分子(节点7)/确定发展对象(节点14)/接收预备党员前(节点19)/预备党员转正前(节点25)」四处设公示；公示中=蓝色+倒计时；公示期内收异议→「异议中（红色）」分支，异议处置完成方可继续；公示组件含倒计时+异议入口+异议处置记录。
  - 状态机分支：含「退回/终止」分支，终止须填原因并归档留痕。
  - 提交前校验清单须合并：公示未完成/异议未结案 + 材料缺失 + 时间不足 一并拦截。

### 3.4 监督考核（4.6）PC
- 目标：积分透明可追溯、考核闭环、风险预警统一聚合、党风廉政闭环。
- 核心模块/组件：党员积分（总分+基础/加分/扣分明细+排名+申诉状态，变更记录不可编辑）；支部考核（自评→上级考评→结果反馈→整改销号 四步，问题设责任人与整改期限）；预警清单（换届/党费/学时/组织生活/发展党员等统一聚合，按风险等级+责任组织处理）；党风廉政（新增子模块入口：信访举报受理闭环 + 党纪处分工作流）。
- 关键交互：积分明细一键溯源（关联业务单据 ID）；申诉发起→状态机；预警清单筛风险等级+责任组织+处理；党风廉政子页入口。
- 必须体现的状态与数据：积分正负明细与来源业务 TAG；申诉状态色；考核四步进度；预警分级聚合；信访/处分闭环状态。
- 蓝色新增项覆盖（验收要点③）：
  - 积分明细溯源：每条积分关联来源业务（组织生活/学习/奖惩/志愿服务）单据 ID，支持一键溯源。
  - 积分申诉状态机：发起→待审核(蓝)→通过(绿)/驳回(红)→完成；驳回须填原因并可二次复核。
  - 党风廉政·信访举报受理闭环：登记→分办→初核→立案/了结→反馈（蓝处理中/红风险/绿了结）；举报人信息脱敏仅受理角色可见。
  - 党风廉政·党纪处分工作流：警告/严重警告/撤销党内职务/留党察看/开除党籍 分级审批与执行归档。
  - 预警清单补充：换届预警、信访超期预警纳入聚合。

### 3.5 党委数据驾驶舱（4.8 大屏）深色
- 目标：宏观数据可视化、实时预警监控、多维度下钻，服务党委决策督导。
- 核心模块/组件：深蓝灰背景，标题区党徽+系统名+统计时间；顶部核心指标（党组织总数/党员总数/本月组织生活数/当月党费收缴率，翻牌效果）；左区（组织层级旭日/树图、党员年龄/身份分布）；中区（参会率/学习完成率/党费收缴率趋势、年度达标仪表盘）；右区（支部考核排行、党员积分排行、待办/超期/预警数量）；底部红色滚动预警栏。
- 关键交互：旭日图点击下钻下级组织；任一图表点击下钻至 PC 管理端对应清单；底部预警栏滚动。
- 必须体现的状态与数据：核心指标实时（T+0）；趋势类 T+1；排行 Top10/倒数 Top5；预警数量卡片。
- 蓝色新增项覆盖（验收要点⑥）：
  - 右区预警数量扩展为六类聚合：待办 / 超期 / 红色预警 / 信访在办 / 转接异常 / 换届临期。
  - 底部红色滚动预警栏新增专项条目：发展党员逾期、党费连续欠缴、组织关系转接异常、信访超期未处置；点击均可下钻至 PC 对应清单。

## 五、原型构建建议

### 5.1 推荐页面模板类型
| 页面 | 模板类型 |
| 首页工作台 | 工作台混合模板（指标卡+双栏列表+日历+趋势） |
| 组织与党员 | 主从模板（左树+右详情/列表）+ Tab 详情页 |
| 发展党员 | 流程向导模板（步骤条+当前节点表单+固定时间轴+状态机） |
| 监督考核 | 列表页（筛选+表格+分页）+ 抽屉/子页（积分溯源、党风廉政） |
| 党委数据驾驶舱 | 大屏 Dashboard 模板（深色、顶部通栏+左中右三栏+底部预警栏） |

### 5.2 一致性约束（下游必须遵守）
1. 框架统一：所有 PC 页共用「左导航216+顶栏64+外边距24+卡片间距16」外壳；驾驶舱独立大屏外壳但状态色语义一致。
2. 状态色唯一语义：红=风险/须处理、橙=即将到期/待补充、蓝=处理中、绿=完成、灰=非活跃；所有状态标签必须含文字+色块，不单靠颜色传达。
3. 通用组件复用：待办卡、指标卡、组织树、筛选区、业务表格、详情摘要卡、流程时间轴、状态机、公示、导入、证明、举报、申诉 等组件在所有页面保持同一视觉与交互。
4. 四类通用页布局一致：列表页＝筛选区→工具栏→表格→分页；详情页＝摘要卡→Tab→流程/操作记录；流程页＝步骤条+当前节点+时间轴；台账页＝完整度清单+预览+导出。
5. 安全合规可见反馈：脱敏、权限隔离、二次确认、操作留痕必须在页面有明确可见反馈。
